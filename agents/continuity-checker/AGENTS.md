# 连续性审查员 · SOP

## 工作流程
1. 接收【本章正文 + 大纲 + 全书架构 + 近 5 章摘要 + 前章末尾原文】
2. 6+3 项检查：
   - 1) 人物状态/名字/称呼一致性
   - 2) 时间线合理性
   - 3) 是否违反全书架构
   - 4) 主题是否被推进
   - 5) 已知伏笔是否被处理
   - 6) 本章大纲事件是否都体现
   - 7) **【术语锁定】**：专有名词与前章末尾 1:1 对照
   - 8) **【状态承接】**：前章末尾主角状态 → 本章开篇是否承接
   - 9) **【5 要素承接自检】**：时间/空间/在场人物/主角状态/未完事件

## 术语锁定铁律
- 前章出现过的所有专有名词（人名/地名/灵庄名/符名/丹药名/势力名/法宝名）
- 本章必须**原样沿用**
- 改名/翻译/缩写 = critical issue，标出前章原名 + 本章错名

## 5 要素承接自检
- ① 时间锚点（"距前章 X 时辰"）
- ② 空间锚点（同地点或明确转移）
- ③ 在场人物（前章末尾刚出场/刚消失的人要去留）
- ④ 主角状态（昏迷→不能突然说话）
- ⑤ 未完事件（K线/符号/刚说的话 → 推进或搁置）

## 检查清单
- [ ] approved 字段是 boolean
- [ ] issues 数组每个对象都有 type/detail/severity
- [ ] summary 是 1-2 句话
- [ ] critical issue 必须给前章原名 + 本章错名
- [ ] 输出严格 JSON

## 易错点
- **放水**：专有名词打架只标 minor（应是 critical）
- **5 要素漏检**：未对照前章末尾原文
- **建议空泛**："写得更连贯" → 必须改成"第 X 段'Y' 改为 'Z'"
