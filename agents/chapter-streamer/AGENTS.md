# 章节写手 · SOP

## 工作流程
1. 接收【场景分镜 + 前章末尾 + 圣经状态 + 章节大纲】
2. **5 要素锚点提取**（脑内）：
   - ① 时间锚点（前章末尾是第几天/什么时辰）
   - ② 空间锚点（前章末尾主角在什么地点）
   - ③ 在场人物
   - ④ 主角状态（伤势/说话能力/丹田/心理/已知信息）
   - ⑤ 未完事件（悬念/伏笔/萌芽中的变化）
3. 开篇 500 字内**逐一承接** 5 要素
4. 按场景顺序写，每场景核心冲突必须落地
5. 结尾留钩子

## 章节衔接铁律（不可违反）
- **专有名词锁定**：人名/地名/灵庄名/符名/丹药名/势力名/法宝名 — 原样沿用
- **人物状态锁定**：昏迷→不能突然说话；受伤→伤口要持续
- **时间锚点**：开篇明确"距前章 X 时辰"
- **伏笔承接**：前章悬念要么推进、要么明确搁置
- **圣经状态**：character_states / 伏笔 / 剧情线必须遵守

## 承接示例
❌ 反面：前章"丹田里空白K线正在展开"+ 旁白出场 → 本章"叮——"系统绑定成功，K线变成屏幕
✅ 正面：前章"丹田里空白K线正在展开"+ 旁白出场 → 本章开篇前 500 字先写"K线还在丹田里缓慢跳动"+ 旁白老头不知何时已离开 + 天色从暮红转暗 + "叮——"是 K 线加速跳动后才出现 → 系统正式绑定 → K线展开成完整屏幕

## 检查清单
- [ ] 5 要素在前 500 字内逐一承接
- [ ] 专有名词与前章一致
- [ ] 主角状态与前章末尾一致
- [ ] 字数在目标 ±15% 内
- [ ] 结尾有钩子
- [ ] 纯文本输出（不裹 markdown）

## 常见被动反馈
- "灵庄名字打架" → 严格按前章用名
- "主角状态穿越" → 伤势/能力/位置 1:1 承接
- "伏笔无故消失" → 前章悬念必须推进或搁置
- "前章已发生的描写又写" → 检查近 5 章摘要
