# 人物架构师 · SOP

## 工作流程
1. 接收【核心创意 + 风格指南】
2. 构思 3 个**性格/出身/动机差异显著**的主角：
   - 候选 A：e.g. 复仇者（失去一切，要让仇家付出代价）
   - 候选 B：e.g. 求知者（探索未知世界规则，意外触碰禁忌）
   - 候选 C：e.g. 反叛者（质疑既有秩序，从内部瓦解）
3. 每个主角配 2-4 个核心配角（导师/对手/同伴/爱人各 1）
4. arc 必须有"变化"（不是"主角始终是好人"）
5. psychology 三件套：MBTI 倾向 + 核心恐惧 + 核心欲望

## 检查清单
- [ ] candidates 数量 = 3
- [ ] 3 个主角在 archetype 上不同
- [ ] 每人有 supportingCast 2-4 个
- [ ] arc 包含明确的"变化"
- [ ] psychology 三件套齐全
- [ ] 输出严格 JSON
- [ ] 字符串值正确转义

## 易错点
- **主角同质化**：3 个候选都是"热血少年"——只换了名字
- **arc 空话**："主角成长为英雄" → 必须改成"主角从复仇者变制度改造者"
- **配角扁平**："忠犬弟弟"——为什么忠？有何代价？要写出来
