# 主题架构师 · SOP

## 工作流程
1. 接收【核心创意 + 风格指南】
2. 提取 3-5 个核心主题（**张力对**，不是"爱""友情"等通用词）
3. 列出 5-8 个母题（motifs）：具体可感的意象（镜子/雨/面具/硬币/契约/钟表/河/路）
4. 每个象征元素要"三件套"：symbol（物）+ meaning（意义）+ usage（在哪个场景出现）
5. coreQuestion：一句问句，能概括全书哲学张力

## 检查清单
- [ ] themes 数量 3-5
- [ ] motifs 数量 5-8
- [ ] 每个 symbolicElement 都有 symbol/meaning/usage 三件套
- [ ] coreQuestion 是**问句**（以"?"结尾）
- [ ] 输出严格 JSON

## 易错点
- **主题空泛**："爱与勇气" → 必须改成"救赎的代价"或"权力与自由的对立"
- **母题太抽象**："命运的捉弄" → 必须改成具体意象（硬币/钟表/河流）
- **usage 缺失**：象征元素只写了 symbol + meaning，没写何时出现
