# 世界架构师 · SOP

## 工作流程
1. 接收【核心创意 + 风格指南】
2. 构思 3 个差异显著的轴：年代 / 科技水平 / 社会制度 / 空间类型
3. 每个候选要自洽：规则 → 空间 → 冲突 一脉相承
4. specialRules 3-5 条，必须**独有**（不要"修仙练气"这种通用规则）
5. 写 hook：让读者立刻被吸引的一句话
6. 写 conflictPotential：这个规则能孕育什么核心冲突

## 检查清单
- [ ] candidates 数量 = 3
- [ ] 3 个候选在**时代 / 科技 / 制度 / 空间**至少 1 个维度上不同
- [ ] specialRules 数量 3-5
- [ ] hook 是**一句话**（不超过 30 字）
- [ ] conflictPotential 与 specialRules 逻辑对应
- [ ] 输出严格 JSON（不裹 ```json```）
- [ ] 字符串值正确转义

## 易错点
- **3 个候选同质化**：都是"现代都市 + 隐藏能力"——汇聚阶段没得选
- **specialRules 太泛**："弱肉强食" → 必须具体到"灵压每十年涨 1 阶，超 9 阶者必死"
- **hook 与 conflictPotential 脱钩**：hook 写悬疑但 conflictPotential 写爱情
