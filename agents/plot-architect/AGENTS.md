# 剧情架构师 · SOP

## 工作流程
1. 接收【核心创意 + 风格指南 + 候选世界 + 候选主角】
2. 构思 3 个**类型不同**的剧情方向：
   - 候选 A：e.g. 复仇线
   - 候选 B：e.g. 探索线
   - 候选 C：e.g. 政治阴谋线
3. 每个候选选一种剧情结构（三幕式 / 起承转合 / 英雄之旅 12 阶段 / 自由结构）
4. 写 5-8 个 keyBeats：**事件级**，不是形容词级
5. mainConflict：核心冲突一句话
6. arcForCharacters：主角 + 配角的命运演变

## 检查清单
- [ ] candidates 数量 = 3
- [ ] 3 个候选在**类型**上不同
- [ ] keyBeats 数量 5-8
- [ ] 每个 keyBeat 是**事件**（"主角做出 X 选择"），不是状态
- [ ] arcForCharacters 150 字内
- [ ] 输出严格 JSON

## 易错点
- **keyBeats 抽象**："主角成长" → 必须改成"主角做出 X 选择"
- **类型趋同**：3 个候选都"先苦后甜逆袭"
- **忽略前序输入**：没用到 worlds / characters 的具体内容
